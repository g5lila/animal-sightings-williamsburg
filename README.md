# Abstract
What wildlife lives on campus, and how does it change by season? Here are animal sightings logged around William & Mary during winter and spring, then visualized the same dataset in different ways to show how chart choices shape what you see in the data. The project was inspired by Giorgia Lupi and Stefanie Posavec's *Dear Data*.

# Methodology and Tools
We recorded each sighting with date, location, animal type, behavior, and a descriptor for unidentified species. We include a bar chart, heatmap, and stacked chart visualizations using tableau and python, plus an interactive parallel categories plot (Plotly) and location maps (Folium). We also have a *Dear Data*-style drawing of the same data, one grouped by day and one by location.

# Conclusion
Squirrels and birds dominated the sightings. Squirrels led in winter, while birds rose in spring, likely due to migration. Overall sightings dropped in spring, largely because of heavy rain. Our two hand drawings looked very different despite using the same data, which shows how much design choices affect interpretation!
